# ALL CHATBOT CREATE

This package contains 10 independent domain-focused Flask + Gemini study chatbots.

## Included chatbots

- `agriculture_environment` — Agriculture & Environment (Agriculture, Horticulture)
- `biotechnology_life_sciences` — Biotechnology & Life Sciences (Biotechnology, Microbiology)
- `medical_allied_health` — Medical & Allied Health (Pharmacy, Physiotherapy)
- `science_research` — Science & Research (Physics, Chemistry)
- `ai_machine_learning` — Computer Science – AI & Machine Learning (AI, Machine Learning)
- `data_science_analytics` — Computer Science – Data Science & Analytics (Data Science, Data Analytics)
- `cybersecurity_networking` — Cybersecurity & Networking (Cybersecurity, Network Engineer)
- `cloud_devops` — Cloud & DevOps (Cloud Engineer, DevOps Engineer)
- `electronics_semiconductor` — Electronics & Semiconductor (VLSI, Semiconductor Design)
- `embedded_iot` — Embedded & IoT (Embedded Systems, IoT Engineer)

Each folder is standalone and contains `app.py`, `index.html`, `chatbot_config.py`, `requirements.txt`, `.env`, `.gitignore`, and `README.md`.

The `.env` files contain a placeholder only. Add your own `GEMINI_API_KEY`; never commit a real API key.
